# Project Statement

## Problem Statement

Small vehicle-rental or fleet operations often need to maintain vehicle records, customer details, rental transactions and availability status. Maintaining these records manually can lead to duplicate entries, incorrect availability information and difficulty preparing summaries.

The Vehicle Management System provides a simple command-line solution for storing and processing these records in a structured SQLite database.

## Scope

The project covers:
- Vehicle registration and fleet status management.
- Customer registration.
- Rental creation and vehicle return.
- Automatic rental charge calculation.
- Basic operational reports.

The project does not include online payments, GPS tracking, insurance integration or a graphical/web interface.

## Target Users

- Small vehicle-rental operators.
- College project demonstrators.
- Fleet administrators learning database-backed Python applications.

## High-Level Features

- Vehicle CRUD operations.
- Customer registration and listing.
- Rental and return workflow.
- Availability tracking.
- Revenue and fleet reports.
- Validation and error handling.
